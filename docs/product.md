# PayFlow: how it works now

_Status: to write. Each section is filled in from the current code, one at a time._

PayFlow tracks installment purchases: you enter a total amount and a number of months, the app splits it into monthly payments, and you mark payments as paid.

Each feature lists **user stories** ("As a user I can…") with **acceptance criteria**, then the **rules** (limits, calculations) and the **screens** where it lives. Known bugs are marked **(bug)**, so later specs can fix them on purpose.
